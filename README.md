# Python - Do Básico à Automação e IA

Repositório dedicado ao aprendizado de Python através de curso na Udemy, reunindo anotações, exercícios práticos e códigos de estudo. O projeto serve como fundação de sintaxe e lógica com foco no desenvolvimento de automações e soluções com Inteligência Artificial.

---

## 🎯 Objetivos de Aprendizado

- [x] Fundamentos de sintaxe e tipos primitivos
- [x] Estruturas de controle de fluxo e condicionais
- [ ] Estruturas de repetição (`for`, `while`) e coleções (listas, tuplas, dicionários)
- [ ] Funções, escopo e modularização
- [ ] Manipulação de arquivos e dados (CSV, JSON, APIs)
- [ ] Automação de processos (scripts, web scraping e integração de serviços)
- [ ] Aplicações de Inteligência Artificial e Machine Learning

## 🚀 Como Executar

Clone o repositório e execute qualquer script via terminal:

```bash
# Clonar o repositório
git clone https://github.com/mkzzo/python-szzzz.git

# Acessar a pasta
cd python-szzzz

# Executar um script específico (exemplo)
python conceitos_iniciais/tipos_de_dados/inicio.py
```
